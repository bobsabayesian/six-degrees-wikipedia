Search

Bidirectional search: outgoing links from the first topic, incoming links to the second. A higher cap finds shorter paths but makes more API requests.

Ignore list

Ignored pages never appear as branches, and the search won't route through them. Redirects (e.g. “NYT”) are resolved. You can also click a page on the map and choose “Ignore page”. If an ignored page is on the current path, click Find again.

Branches

Nudge: drag any node or label on the map. Click one, then use the arrow keys (Shift = bigger steps). Double-click to reset that item. Moving one item doesn't disturb the rest; 🎲 or a new seed starts over.

Pens

Assign pens

Each pen exports as its own layer (1 name, 2 name…), the naming AxiDraw/Inkscape uses for multi-pen plots. Layer order = pen order.

Labels are drawn with single-stroke Hershey fonts, so they plot as real pen lines (no Inkscape text conversion needed).
